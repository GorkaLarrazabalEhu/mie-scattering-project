# Electrodynamic Scattering Project

University project involving numerical simulations of electromagnetic
scattering by spherical particles.

## Structure

- `Fortran/` – Core numerical solvers
- `Python/` – GUI and plotting tools
- `Latex/` – Article and figures
- `Simulaciones/` – Raw simulation outputs (not tracked by git)

## Notes

This repository tracks source code and documentation only.
Generated files and large datasets are excluded via `.gitignore`.
